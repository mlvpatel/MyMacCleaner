# Orphaned Files

Orphaned Files is an offline review page for local app-leftover evidence.

## What it shows

The scan looks for files that appear related to apps that may no longer be present. Evidence can include application support folders, preferences, logs, cache-like locations, and saved-state paths when they are readable.

The result is a lead for investigation, not proof that a file is unnecessary.

## How to use it

1. Run a scan from **Orphaned Files**.
2. Review the app name, path, category, and size estimate for each item. A search that matches nothing says so and offers **Clear Search**. Leaving the page while a scan runs stops it; when you come back the page says the last scan stopped and still shows the results of the last finished scan.
3. Use each row's **Show in Finder** button to inspect the source location. The button is always shown, so the keyboard and VoiceOver can reach it. The list has no checkboxes or selection; **Open in Experience** leads to the only screen that can move files.
4. Be cautious with files that may contain settings, licenses, projects, credentials, or user content.

## What this page does not do

This feature reports leftover-looking evidence only. It does not remove files, move items to Trash, alter app data, or decide that an item is safe to discard.
