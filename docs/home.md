# Home & Smart Scan

Home is the local review dashboard for storage, memory, installed-app counts, permission-aware scanning, and safe navigation to detailed views.

## Dashboard

The dashboard shows current storage use, memory in use, a reviewable storage estimate after a scan, installed-app count, and a high-level health indicator. Values are local observations and can change while the app is open.

## Smart Scan

Smart Scan gathers a categorized storage review. It may request optional file access so it can report a more complete picture; you can continue with limited access if you decline.

1. Select **Smart Scan**.
2. Wait for the category-by-category progress to finish.
3. Review the categories and individual selections in the results card.
4. Use the explanation and detail links to understand the evidence behind a result.

## Quick actions

- **Trash review** explains the safety boundary for reviewing local storage.
- **Memory** opens the Performance page for current CPU, memory, swap, and timestamp context.
- **Large files** opens the detailed storage view.

## Phase-0 limitation

Home prepares evidence for review and routes to observational views. It does not alter local files, memory, processes, or macOS settings.
