# Disk Cleaner & Browser Privacy

Disk Cleaner and Browser Privacy are local review surfaces for storage categories and browser-data evidence.

## What it shows

The pages organize scan results by category, source path, size estimate, and local evidence. Browser Privacy can show browser-related categories when those locations are readable.

Scan results are review material. Some values depend on macOS permissions and may be incomplete when access is limited.

## How to use it

1. Start a scan from Home or Disk Cleaner.
2. Review category names, paths, and size estimates.
3. Use the safety explanation when you need to understand why a result is review-only.
4. Grant macOS file access only when you want a more complete local scan.

## Phase-0 limitation

These pages present storage evidence only. They do not delete files, empty Trash, change browser data, run cleanup scripts, or alter system folders.
